# Operational hardening validation

Development worktree based on `5314f2d`, tested on 2026-09-10 with Rust 1.98.0,
Node 24.20.0 and Python 3. These are local development observations, not evidence
of live GitHub delivery, account access, model quality or week-long operation.

## Regression coverage

`make check` covers rustfmt, clippy, the dashboard build, Svelte/TypeScript and
Prettier. `make test` covers Rust behavior, both deterministic runner protocols,
real temporary Git repositories, packaging guards, and desktop/mobile browser
checks. The hardening regressions exercise changed limits across restart,
publication races and identity mismatches, total branch ordering, typed stale
recovery, supersession/obsolete objectives, one-shot restart boundaries, paused
cleanup, preserved unresolved evidence and symlink refusal, separate configured
runner storage measurement, stable problem identity, PR outcome observation and
late-response handling in task details.

The actual pinned Codex 0.153.4 and OpenCode 1.18.30 clients also completed the
isolated contracts in `tests/contracts.rs`: a completed turn, structured review,
session resume after client restart, and cancellation. Their only model endpoint
was the local synthetic provider in `tests/fixtures/provider.py`. Codex schemas
were generated by that binary and OpenCode's `/doc` was inspected. Required CI
matrix jobs reproduce these contracts without operator credentials.

## History scale measurement

Command: `cargo test --locked --test history_scale -- --ignored --nocapture`.
The fixture stores 4 KiB prompts in 1,000, 10,000 and 100,000 historical task
records. Each measurement includes 20 dashboard snapshots using the debug build.

| Historical tasks | State JSON bytes | Median query time | p95 query time | Peak additional Rust allocations |
| --- | ---: | ---: | ---: | ---: |
| 1,000 | 95,227 | 14.27 ms | 18.04 ms | 1,344,963 bytes |
| 10,000 | 95,528 | 13.99 ms | 23.44 ms | 1,345,563 bytes |
| 100,000 | 95,829 | 16.50 ms | 23.57 ms | 1,346,163 bytes |

These timings are environment-dependent. Allocation measurements cover the Rust
allocator, not SQLite's C allocations or total process RSS. The regression also
asserts the 300-task summary bound and a response below 1 MiB for this fixture.
A separate test includes an old blocked task outside the recent window and checks
that authoritative attention counts and filtered history still expose it.
